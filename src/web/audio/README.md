# Chess move sounds

`move.wav` and `capture.wav` are local copies of
[Chess_analyzer's move sound](https://github.com/imutkarsht/Chess_analyzer/blob/master/assets/sounds/move.wav)
and [capture sound](https://github.com/imutkarsht/Chess_analyzer/blob/master/assets/sounds/capture.wav).
The project credits these generated sounds under the
[CC0 1.0 Universal dedication](https://creativecommons.org/publicdomain/zero/1.0/),
as recorded in its [credits](https://github.com/imutkarsht/Chess_analyzer/blob/master/CREDITS.md).

The files are served locally by Whisker, so playback does not depend on a third
party host.
